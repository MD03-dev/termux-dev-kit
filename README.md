# 🚀 Termux Dev Kit

> Biến chiếc điện thoại Android thành môi trường lập trình thực thụ chỉ với 1 lệnh.  
> Không cần root. Không phá hệ thống. Không cần PC.

## Repo này để làm gì?
Termux Dev Kit là bộ script + tài nguyên giúp bạn:
- Cài Termux xong không biết làm gì -> install.sh setup sẵn mọi thứ
- Cài package lẻ tẻ mất thời gian -> setup.sh cài 1 lần đủ tool
- Sợ mất code khi reset máy -> backup.sh backup 1 lệnh
- Máy đầy dung lượng -> clean.sh dọn cache
- Không biết tool nào hay -> AWESOME.md tổng hợp sẵn

## Hướng dẫn sử dụng
1. Cài môi trường cơ bản: bash install.sh
2. Cài tool dev bổ sung: bash setup.sh
3. Backup config: bash backup.sh
4. Dọn cache giải phóng dung lượng: bash clean.sh
5. Test tốc độ mạng: bash speedtest.sh
